The builder on Google Cloud, checked here.

An Ethereum block builder runs in an Intel TDX trust domain on Google Cloud as one Lean program of 4.0 MB, with no Linux under it, and bids at four relays. Relays list each bid beside the key that signed it. This page checks, in your browser and with nothing sent anywhere, the quote in which that machine says the key is its own.

    What this page does not show

    Where you are still taking someone's word

    • That the measurement is of the source. The record says which RTMR1 belongs to the program, and this page takes that from us. To take it from nobody, build the image from the commit named and run the command below: it works RTMR1 out from the file you built. A machine of GitHub's does that each time the record changes; whether it passed is public, and GitHub shows the log to anyone signed in.
    • That the firmware is Google's. MRTD names the firmware that started the guest and stays under it. Google signs a statement for that measurement; the command below fetches and checks it, and this page does not. What that firmware does is Google's word either way.
    • Whether Intel still stands by the platform. This page does not ask Intel whether the processor's microcode and TDX module are current or whether a certificate has been revoked. The command below does.
    • That the quote is fresh. It is from when the guest last told the feeding machine its key, and is no older than the block named above. The guest's port is open to that machine alone, so you cannot ask it yourself.
    • This page. It and the two files come from one site. Someone who could change the site could change all three, which is the other reason to run the command.
